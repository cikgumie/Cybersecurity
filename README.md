# 🛡️ Wira Siber — 5 Cara Menjaga Keselamatan Siber Murid
### *"Bijak Klik, Selamat Selalu!"*

Bahan pembelajaran dan pembentangan **interaktif dwifungsi (Laman Web + Slaid Smart Board)** yang disusun semula berpandukan **5 Cara Menjaga Keselamatan Siber dalam Kalangan Murid** (Inisiatif Sekolah Selamat Murid Sejahtera • SMK Taman Molek).

---

## 📌 5 Pilar Utama Keselamatan Siber Murid

| Pilar | Fokus Utama | Aktiviti & Kandungan Interaktif |
|---|---|---|
| **1. 🔒 Lindungi Maklumat Peribadi** | Jangan kongsi nama penuh, alamat, no telefon, kata laluan atau maklumat sekolah | Maklumat Rahsia vs Umum, **Senarai Semak Privasi Profil** (cincin markah), Permainan *Kebenaran App: Logik atau Pelik?* |
| **2. 🔐 Gunakan Kata Laluan Kuat** | Gabungan huruf besar/kecil, nombor & simbol. Rahsia mutlak, jangan kongsi | Kata laluan popular dalam kamus penggodam, **Makmal Penguji Kata Laluan 🧪**, **Penjana Frasa Laluan 🎲**, formula **2FA** |
| **3. 🧠 Berfikir Sebelum Kongsi** | Fikir dahulu sebelum muat naik kandungan. Elak memudaratkan diri/orang lain | Konsep **Jejak Digital** (*Padam ≠ Hilang*), **Ujian Nenek**, Permainan Kad *Kongsi atau Jangan?* (8 situasi) |
| **4. 👤🚫 Elak Orang Tidak Dikenali** | Jangan terima rakan orang asing & elak berbual di media sosial/game | Bahaya Phishing & Umpan Hadiah, **Detektif Telefon Pintar 🔍** (6 tanda bahaya), Permainan *Selamat atau Phishing?*, Jerat Akaun Keldai, Formula **Henti • Fikir • Semak** |
| **5. 📢 Laporkan Perkara Mencurigakan** | Lapor gangguan, buli siber atau kandungan tidak sesuai kepada guru/kaunselor | Buli siber & peranan **Pembela**, **Senario Interaktif Aina (A–D)**, Pelan Tindakan 4 Langkah, Talian Bantuan 997, Cyber999, Semak Mule, Talian Kasih 15999 & Guru Kaunseling |
| **🏆 Kuiz & Ikrar** | Penilaian & komitmen wira siber | **Kuiz Pasukan 15 Soalan** (2–4 pasukan, pemasa, papan markah, podium juara), **Ikrar Wira Siber** (konfeti!) |

## 🎮 Kawalan & Kekunci Pintas Semasa Pembentangan

| Kekunci / Butang | Fungsi |
|------------------|--------|
| **`P`** | Bertukar antara **Mod Laman Web** dan **Mod Pembentangan Slaid** |
| **`Esc`** | Keluar dari mod pembentangan kembali ke laman web |
| **`←` `→`** / **`PageUp` `PageDown`** / Leret Skrin | Slaid sebelum / seterusnya |
| **`M`** | Membuka laci senarai semua slaid (lompat terus) |
| **`N`** | Membuka **Nota Guru & Pembentang** bagi slaid semasa |
| **`F`** | Skrin penuh (*Fullscreen*) |
| **`S`** | Menghidupkan / mematikan bunyi kesan audio |

## 🚀 Penggunaan Luar Talian & GitHub Pages

- **Luar Talian**: Buka sahaja fail `index.html` pada pelayar web komputer atau smart board bilik darjah.
- **GitHub Pages**: Muat naik semua fail ke repositori GitHub dan aktifkan GitHub Pages pada cawangan `main`.
